# svelte-fluentui 2.0.0-rc01 — Release Notes

**Released:** _unreleased_ · **Pre-release** (`npm install svelte-fluentui@rc`)

These notes cover the changes since **1.6.0-rc07**, the last version on npm.

This is a **major release: breaking, with no aliases.** Before the first public release the whole
API was revised for consistency: every callback prop is lowercase (`onfileselected`, not
`onFileSelected`), one name per concept across components (`open`, `value`, `multiple`, …), prop
values are lowercase / kebab-case, and shared logic moved into helpers. Code written for 1.x needs
updating: the old names are gone.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/KeenMate/svelte-fluentui/blob/prod/CHANGELOG.md) (section
2.0.0-rc01); this document is the upgrade guide and the highlights.

## Breaking changes

### Renamed props and values

Same meaning, consistent names: `multiple` (never `multi`), correct spelling (`dismissible`),
kebab-case values (`"2-digit"`, `"move-up"`), one name per concept across components.

| Component | 1.x | 2.0 |
|---|---|---|
| Accordion, Listbox | `multi` | `multiple` |
| Alert, Dialog | `dismissable` | `dismissible` |
| Calendar, DatePicker | `dayFormat="two_digit"` | `dayFormat="2-digit"` |
| QuickGrid editorOptions | `optionsLoadTrigger` `"oneditstart"` / `"ondropdownopen"` | `"edit-start"` / `"dropdown-open"` |
| QuickGrid rowToolbar | `"moveUp"` / `"moveDown"` | `"move-up"` / `"move-down"` |
| AccordionItem | `header` (string) + `heading` (snippet) | one `heading` that takes a string or a snippet |
| Anchor | `iconStart` / `iconEnd` snippets | `start` / `end` |
| Autocomplete | `startIcon` / `endIcon` snippets | `start` / `end` |
| Checkbox | `withIntermediate`, `threeStateOrderUncheckToIntermediate`, `intermediateMessage` | `threeState`, `threeStateOrder` (`"checked-first"` or `"indeterminate-first"`), `indeterminateMessage` |
| TimePicker | `use24Hours`, `useAmPm` | `hourCycle` (`"h23"` or `"h12"`, Intl naming) |
| MenuButton, ContextMenu items | `MenuButtonItem` `{label, icon, disabled, visible, danger, dividerBefore, onclick(), children, expandable, defaultExpanded}` | `MenuEntry` `{text, icon, isDisabled, isVisible, isDanger, onClick(detail), children, isExpandable, isExpanded}`; dividers are their own `{divider: true}` entries; `MenuButtonItem` type removed |
| Dialog | `primaryAction` / `secondaryAction`: `{label, disabled, onClick() → false keeps open}` | action items: `{text, icon, isDisabled, onClick(detail), appearance, shouldCloseOnClick}` + `onAction` / `beforeActionCallback` on Dialog |
| CommandPalette items | `CommandPaletteItem` `{title, disabled, onSelect()}` | action item `{text, isDisabled, onClick(detail), …}` (+ `meta`, `badge`, `group`, `keywords`, `href`) |
| CommandPalette | `filter(items, query)` | `filterCallback({items, term})` |
| Toast | `topAction` / `primaryAction` / `secondaryAction`: string | `string` or an action item (a string gets `id` `top` / `primary` / `secondary`) |
| TopNav items | `{label, href, icon (text glyph), onClick()}` | action item `{text, href?, icon (Fluent name or snippet), isDisabled, onClick(detail)}` (type `TopNavItem`) |
| QuickGrid rowToolbar items | `{id, icon, iconSnippet, title, label, row, group, type, danger, disabled(row, index), onclick({row, rowIndex})}` | action items `{id, action, icon (name or snippet), text, tooltip, isTextVisible, toolbarRow, isDanger, isDisabled / getIsDisabledCallback({row, rowIndex}), onClick(detail)}`; groups are `{divider: true}` entries |
| QuickGrid contextMenu items | `{id, label (string or fn), icon (text glyph), disabled, visible, danger, dividerBefore, type, onclick(ctx)}` | menu entries `{id, action, text / getTextCallback, icon (Fluent name or snippet), isDisabled / getIsDisabledCallback, isVisible / getIsVisibleCallback, isDanger, onClick(detail)}` + `{divider: true}`; built-ins by name |
| QuickGrid | `showRowActions`, `rowActions` (deprecated aliases) | removed — use `showRowToolbar`, `rowToolbar` |
| QuickGrid context ctx | `colIndex` | `columnIndex` |
| exports | `AnchorButton` (alias of `Anchor`) | removed — use `Anchor` |
| Icon | `primaryFill` | removed — use `color` / `customColor` |
| Tabs | `overflow`, `moreButtonId`, `styleMoreValues` (no effect since the rewrite) | removed — use `responsive="menu"` |
| QuickGrid columns | `isEditable` (boolean or `(row) => boolean`), `isTree` | `editable` (boolean) + `getIsEditableCallback({row, column})`, `tree` |
| QuickGrid | `isRowEditable` (boolean or `(row) => boolean`) | `rowEditable` (boolean) + `getIsRowEditableCallback({row})` |

### Events and callbacks: camelCase, one `ctx` object

Events a component defines are now `on` + PascalCase and receive **one object** (`ctx`), so fields can
be added later without breaking you. Lowercase `on*` props are only real browser events, forwarded
untouched (they receive the native `Event`). Functions whose return value is used are named
`…Callback` (`before…Callback` can veto, `get…Callback` extracts a value).

```svelte
<!-- 1.x -->
<Switch onchange={(checked) => save(checked)} />
<!-- 2.0 -->
<Switch onChange={({checked}) => save(checked)} />
```

| Component | 1.x | 2.0 |
|---|---|---|
| Switch | `onchange(checked)` | `onChange({checked})` |
| Slider | `onchange(value)`, `oninput(value)` | `onChange({value})`; live value via `bind:value` |
| RadioGroup | `onchange(value)` | `onChange({value})` |
| Textarea | `oninput(value)`, `onchange(value)` | `onChange({value})` on commit; `oninput` / `onchange` are now the native events |
| Accordion | `onchange(value)` | `onChange({value})` |
| AccordionItem | `onchange(ev, isExpanded)` | `onExpandedChange({expanded, sourceEvent})` |
| Checkbox | `onclick(ev, previousValue)` | `onChange({checked})` (`null` = indeterminate); `onclick` is now the native click event |
| Listbox | `onchange(ev)` | `onChange({value})` on user selection; `onchange` is the native event |
| Select | `onchange({value, selectedOption, data})` (`value` was `""` when `multiple`) | `onChange({value, option})` — `value` is the new bound value (array when `multiple`), `option` is `{value, text, data}`; no longer fires when re-picking the selected option |
| Combobox | `onchange(value)` | `onChange({value})` (always an array) |
| Combobox | `onsearch(query)` | `onSearch({term})` |
| Combobox | `filter(query, option)` | `filterCallback({term, option})` |
| TextField | `oninput`, `onchange`, `onkeydown`, `onkeyup`, `onfocus`, `onblur` (hand-forwarded) | native events and attributes (incl. `class`) forwarded via `...rest`; new `onChange({value})` on commit |
| NumberField | same hand-forwarded native events | native via `...rest`; new `onChange({value})` on commit |
| Search | `oninput(value)`, `onchange(value)` | `onSearch({term})` (debounced by `immediateDelay`), `onChange({value})` on commit; `oninput`/`onchange` are native |
| Search | `focusAsync(preventScroll)` method | `focus(preventScroll)` |
| Calendar | `onDateSelected(value)` + `onDatesSelected(values)` | one `onChange({value})` (`Date` in single mode, `Date[]` in multiple/range); `value` and `selectedDates` are now bindable and updated by the calendar |
| Calendar | `onSelectionError(error)`, code `max_selectable_days_exceeded` | `onSelectionReject(ctx)`, code `max-selectable-days-exceeded` |
| Calendar | `onPickerMonthChange(month)`, `onDayHover(date)` | `onPickerMonthChange({pickerMonth})`, `onDayHover({date})` |
| Calendar | `disabledDateFunc(date)`, `selectableDates(date)`, `highlightDates(date)`, `selectDates(date)` | `getIsDateDisabledCallback({date})`, `getIsDateSelectableCallback({date})`, `getDatesToHighlightCallback({date})`, `getDatesToSelectCallback({date})` |
| DatePicker | `onValueChange(value)`, `onOpenChange(open)`, `onPickerMonthChange(month)` | `onChange({value})`, `onOpenChange({open})`, `onPickerMonthChange({pickerMonth})` |
| DatePicker | `disabledDateFunc(date)`, `selectableDates(date)` | `getIsDateDisabledCallback({date})`, `getIsDateSelectableCallback({date})` |
| TimePicker | `onValueChange(value)`, `onOpenChange(open)`, `disabledTimeFunc(h, m, s)` | `onChange({value})`, `onOpenChange({open})`, `getIsTimeDisabledCallback({hour, minute, second})` |
| Autocomplete | `selectedOptions` (bindable) | `value` (bindable) |
| Autocomplete | `onselectedoptionschange(selected)` | `onChange({value})` |
| Autocomplete | `onoptionssearch(searchText)` → options | `searchCallback({term, signal})` → options (`signal` aborts when a newer search starts) |
| Autocomplete | `ondismissed()` | `onOpenChange({open})` (fires on open and close) |
| InputFile | `uploadFileCallback(file, onProgress, signal, chunk)` | `uploadCallback({file, signal, reportProgress, chunk})` — `file` is the `InputFileItem` (`file.file` is the native `File`) |
| InputFile | `onFileSelected(files)`, `onFileUploaded(file, item)`, `onFileError(file, error, item?)` | `onFileAdd({files})`, `onFileUpload({file, fileIndex})`, `onFileError({file, error})` — `file`/`files` are `InputFileItem`s (rejected files get a transient one) |
| InputFile | `onCompleted()`, `onValidityChange(valid, reasons)` | `onUploadComplete({files})`, `onValidityChange({isValid, reasons})` |
| InputFile | `onItemsChange(items)` (also fired on mount), `onItemRemove(item)` | `onChange({items})` (changes only), `onFileRemove({file})` |
| InputFile | `maxFiles` (alias of `maxFileCount`); `formatLimits` info `maxFiles` | `maxFileCount` only; info field `maxFileCount` |
| Alert, Toast | `ondismiss()` | `onDismiss({sourceEvent})` |
| Chip | `onremove(event)` | `onRemove({sourceEvent})` |
| CompositeBadge | `onlabelclick(ev)`, `onbuttonclick(ev)` | `onLabelClick({sourceEvent})`, `onButtonClick({sourceEvent})` |
| ValidationSummary | `onjumpto(field)` | `onFieldClick({field})` |
| Paginator | `onFirst()`, `onPrevious()`, `onNext()`, `onLast()` (you moved the page yourself) | `onPageChange({pageIndex})`; `currentPageIndex` is bindable and moved by the paginator; `canGoBack`/`canGoForwards` default from the index |
| Grid | `onBreakpointEnter(size)` | `onBreakpointChange({breakpoint})` |
| MultiSplitter | `onresize`, `oncollapse`, `onexpand` with `{index, …}` | `onPaneResize`, `onPaneCollapse`, `onPaneExpand` with `{paneIndex, …}` |
| Tab | `canLeave()` (falsy vetoed) | `beforeLeaveCallback({tab, newTab})` — only `false` vetoes (`undefined` continues); may be async; a throw vetoes |
| Tab | `canClose()`, `oncloseclick()` | `beforeCloseCallback({tab})`, `onTabClose({tab})` |
| Tabs | `ontabchange({tabId, data})` | `onActiveIdChange({activeId, oldActiveId, tab})` — `tab` is `{id, label, data}` (type `TabInfo`) |
| Dialog | `visible` (bindable) | `open` (bindable) |
| Dialog | `onClose()` | `onOpenChange({open})` (fires on open and close) |
| Dialog | `onbeforeclose()` (sync, `false` vetoes) | `beforeCloseCallback({reason})` — may be async; `reason` is `escape` / `close-button` / `overlay` / `dismiss` / `action`; not called for `hide()` from code |
| SiteSettings | `onClose()`; `open` not bindable | `onOpenChange({open})`; `open` bindable |
| Panel | `onclose()` | `onOpenChange({open})` |
| CommandPalette, MenuButton | `onopen()`, `onclose()` | `onOpenChange({open})` |
| ContextMenu | `onopen({x, y})`, `onclose()` | `onOpenChange({open, x, y})` |
| Anchor, AppBarItem, NavExpander, NavItem, NavLink, NavLinkItem | `onClick(ev)` | `onclick(ev)` — the native click event (AppBarItem's was never wired; now it is) |
| CommandPaletteTrigger | `onclick()` (typed without the event) | `onclick(event)` |
| DataGrid | `onCloseColumnOptions`, `onCloseColumnResize` | removed — `<fluent-data-grid>` never fires them |
| DataGrid, DataGridRow, DataGridCell | hand-forwarded `onkeydown` / `onclick` / `ondblclick` / `onfocus` | any native event or attribute via `...rest` |
| QuickGrid column | `format(value, row)`, `template(row)` | `getDisplayValueCallback({value, row, column})`, `renderCellCallback({row, column})` |
| QuickGrid column | `filter(filterValue, row)`, `validate(value, row)` | `filterCallback({term, row, column})`, `validateCallback({value, row, column})` |
| QuickGrid column | `onbeforecommit(ctx)`, `oncelledit(ctx)` | `beforeCommitCallback(ctx)` (same result semantics, ctx gains `column`), `editCallback(ctx)` |
| QuickGrid editorOptions | `loadOptions(row, field)`, `onSearch(query, row, signal)` | `loadOptionsCallback({row, column, signal})`, `searchCallback({term, row, column, signal})` |
| QuickGrid | `onfilterchange(filters)`, `onrowchange(detail)` | `onFiltersChange({filters})`, `onRowChange(ctx)` |
| QuickGrid | `onroweditstart`, `onroweditcancel`, `onvalidationerror` | `onEditStart`, `onEditCancel`, `onValidationError` (ctx gains `column`) |
| MenuButton, ContextMenu | per-item `onclick()` only | item `onClick(detail)` + component `onAction(detail)` + `beforeActionCallback(detail)` (`false` cancels) |
| CommandPalette | `onselect(item)` | `onAction(detail)` + `beforeActionCallback(detail)` (can veto navigation rows too); `detail.term` is the search text |
| Toast | `ontopactionclick()`, `onprimaryactionclick()`, `onsecondaryactionclick()` | one `onAction(detail)` (`detail.id` says which) + `beforeActionCallback` |
| TopNav | per-item `onClick()` only | item `onClick(detail)` + `onAction` + `beforeActionCallback` (can veto links) |
| QuickGrid | `ontoolbarclick(detail)` + deprecated `onrowaction(detail)` | one `onAction(detail)` (`source` is `row-toolbar` or `context-menu`; `action`, `id`, `row`, `rowIndex`, plus the cell for the menu) + `beforeActionCallback` |
| QuickGrid | `oncontextmenuopen(ctx)` | `onContextMenuOpen(ctx)` |

### Svelte 5.29 or newer

The library now uses `$props.id()` (Svelte 5.20) and attachments (`{@attach}`, Svelte 5.29). The
`svelte` peer dependency moved from `^5.0.0` to `^5.29.0`.

```sh
npm install svelte@^5.29
```

### Store types renamed (they were shadowed)

The toast and settings stores exported types with the same names as the `Toast` and `SiteSettings`
components, so `import type {Toast} from "svelte-fluentui"` gave you the component, not the store
type. Renamed:

| Before | After |
|---|---|
| `Toast` (store item type) | `ToastInstance` |
| `SiteSettings` (settings store value) | `SiteSettingsState` |

### Placeholder components removed

`Menu`, `MenuItem`, `Tree`, `TreeItem` and `ProgressBar` were exported but rendered an empty
FluentUI element with no props. They are gone. Use `MenuButton` / `ContextMenu` for menus; for a
tree, [`@keenmate/svelte-treeview`](https://www.npmjs.com/package/@keenmate/svelte-treeview).

## Behaviour changes

### MultiSplitter is content-height by default (as documented)

Leftover Blazor CSS forced `height: 100%` on every `MultiSplitter` and `overflow: hidden` on its
panes, overriding the component's own styles. With it removed, a splitter without a `height` prop
sizes to its tallest pane, and panes scroll (`overflow: auto`) instead of clipping. If a splitter
should fill a sized parent, say so:

```svelte
<div style="height: 400px">
	<MultiSplitter height="100%">…</MultiSplitter>
</div>
```

## New API

### Action items: one shape for every menu and toolbar

Menus, toolbars, dialog actions, palette commands and toast actions are moving to one item model
(exported from the package root): `ActionItem` / `MenuItem` / `MenuDivider` / `MenuEntry`, plus
`onAction(detail)` and `beforeActionCallback(detail)` on the component. Run order:
`beforeActionCallback` (`false` cancels) → the item's `onClick` → the built-in behaviour → `onAction`.

```ts
const items: MenuEntry[] = [
  {id: "edit", text: "Edit", icon: "edit", onClick: () => edit()},
  {divider: true},
  {id: "delete", text: "Delete", icon: "delete", isDanger: true, getIsDisabledCallback: () => !canDelete}
]
```

```svelte
<MenuButton {items} onAction={({id}) => track(id)} beforeActionCallback={({id}) => id !== "delete" || confirm("Delete?")}>
  Actions
</MenuButton>
```

Converted so far: **MenuButton**, **ContextMenu**, **Dialog** footer actions, **CommandPalette**, **Toast** links, **TopNav** items, **QuickGrid** row toolbar and context menu. Link items (`href`) can be vetoed by
`beforeActionCallback` too; the click is replayed once allowed, so your router still handles it. Static fields have a `get…Callback` twin that
wins (`getTextCallback`, `getIsDisabledCallback`, `getIsVisibleCallback`, …); `icon` takes a Fluent
icon name or a snippet; `isToggled` makes a checkable item; `shortcut` shows a key hint.

## Fixes

- **Textarea** — `bind:value` now updates while typing (it was one-way).
- **Listbox** — a single-select `value` stays a string after a click, assigning `value` moves the
  selection, and `multi` sets the `multiple` attribute.
- **RadioGroup** — arrow-key selection updates `bind:value` and fires `onchange`; re-clicking the
  checked radio no longer fires `onchange`.
- **MenuButton** — enabled menu items no longer render a stray `disabled` attribute.
- **Calendar / DatePicker / Checkbox / Slider** — no longer touch `window`/`customElements` during server rendering; the locale default falls back to `en-US`.
- **Checkbox / Switch** — the auto-generated label id is stable between server and client (`$props.id()`).
- **Dialog / Panel** — Escape in an open dropdown, picker or menu inside them closes that popup first instead of closing the dialog and leaving the popup on screen.
- **DatePicker** — `minDate` / `maxDate` with a time of day no longer disable that whole day.
- **InputFile** — `formatInputFileSize` prints TB/PB instead of `undefined`.
- No more debug `console.log` output from the theme store and Listbox/Select selection.
- **Autocomplete** — a slow async search response can no longer overwrite newer results; search errors no longer surface as unhandled rejections; clicking inside another component's popup closes the dropdown.
- **QuickGrid** — arrowing through a cell editor's dropdown keeps the highlighted option in view.
- **ToastContainer, QuickGrid, MultiSplitter, Tabs, Textarea/TextField** — no more timers, listeners or polling left running after unmount.
- **Tabs** — tabs added after the first render are measured for the indicator and scroll arrows.
- **CommandPalette / Toast** — z-index fallbacks corrected; toasts follow `--fluent-z-toast`.
- **Styles** — leftover Blazor CSS no longer restyles unrelated page markup (`.grid` tables, `div[part=label]`, `th.column-header`, `div[draggable]`, `a .stack-vertical`).
- **Checkbox** — the box no longer stays visually ticked after the value changes to unchecked.
- **CommandPalette** — opening it via `bind:open` focuses the search input and starts with an empty query.
- **Toast** — clicking an action link no longer adds `#` to the URL.
- **QuickGrid** — on touch devices an outside tap closes the row toolbar again.

## Internal

- Snippet props are typed `Snippet` / `Snippet<[...]>` instead of `any` (the internal `SlotType = any`
  alias is gone). Passing a string or component to a snippet prop is now a type error — it never
  rendered correctly anyway. Snippets with arguments: `AccordionItem.icon(isExpanded)`,
  `Calendar.day(day)`, `CommandPalette.item(item, selected)` / `empty(query)`,
  `TopNav.drawerContent(close)` / `menuToggleTemplate({open, toggle})`.
- FluentUI web components are registered once per component type (module script) instead of on
  every instance.
