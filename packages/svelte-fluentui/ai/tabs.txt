TABS COMPONENT
==============

OVERVIEW
--------
Tab navigation with panels. Custom Svelte implementation (plain <button role="tab">
+ role="tabpanel" divs, NOT fluent-tabs/fluent-tab). <Tab> renders no DOM itself; it
registers with the parent <Tabs>, which renders the tablist + panels.
<Tab> elements go directly between the <Tabs> tags (the `children` snippet).
Supports horizontal and vertical orientation.


BASIC USAGE
-----------
<script>
  import { Tabs, Tab } from "svelte-fluentui"
</script>

<Tabs>
  <Tab id="tab1" label="Overview">
    {#snippet content()}
      <p>Overview content here</p>
    {/snippet}
  </Tab>

  <Tab id="tab2" label="Details">
    {#snippet content()}
      <p>Details content here</p>
    {/snippet}
  </Tab>

  <Tab id="tab3" label="Settings">
    {#snippet content()}
      <p>Settings content here</p>
    {/snippet}
  </Tab>
</Tabs>


TABS PROPS
----------
id?: string
class?: string
style?: string
orientation?: "horizontal" | "vertical"  # Tab direction (default: "horizontal")
activeId?: string                        # Active tab ID (bindable)
showActiveIndicator?: boolean            # Show active indicator (default: true)
responsive?: "scroll" | "wrap" | "menu"  # Overflow handling (default: "scroll")
justify?: boolean                        # Stretch tabs to fill the strip
stripWidth?: string                      # CSS length, mostly for vertical
stripHeight?: string                     # CSS length
swipe?: boolean                          # Swipe to navigate (default: true)
children?: Snippet                       # The <Tab> elements (1.x: childContent)
...rest                                  # Native attributes/events go to the root <div>

CALLBACKS:
onActiveIdChange?: (ctx: { activeId: string, oldActiveId: string | undefined, tab: TabInfo }) => void


TAB PROPS
---------
id: string                     # Required, unique
label?: string                 # Tab label text
disabled?: boolean
ariaLabel?: string
visible?: boolean              # Show/hide tab (default: true)
icon?: Snippet                 # Icon snippet
header?: Snippet               # Custom header (replaces icon + label)
content?: Snippet              # Tab panel content
children?: Snippet             # Panel content between the tags, rendered after `content` (1.x: childContent)
labelEditable?: boolean        # Enable inline label editing (default: false)
showClose?: boolean            # Show close button (default: false)
data?: Record<string, unknown> # Passed back as tab.data in Tabs events/callbacks
class?: string
style?: string

CALLBACKS:
beforeLeaveCallback?: (ctx: { tab, newTab }) => unknown  # return false to veto leaving the active tab; may be async
beforeCloseCallback?: (ctx: { tab }) => unknown          # return false to veto the close; may be async
onTabClose?: (ctx: { tab: TabInfo }) => void


TAB CHANGE EVENT
----------------
<script>
  function handleTabChange({ activeId, oldActiveId, tab }) {
    console.log("Active tab:", activeId)
    console.log("Tab data:", tab.data)
  }
</script>

<Tabs onActiveIdChange={handleTabChange}>
  <Tab id="tab1" label="Tab 1" data={{ section: "overview" }}>
    {#snippet content()}Content 1{/snippet}
  </Tab>
  <Tab id="tab2" label="Tab 2" data={{ section: "details" }}>
    {#snippet content()}Content 2{/snippet}
  </Tab>
</Tabs>


SET ACTIVE TAB
--------------
<script>
  let activeTab = $state("tab1")
</script>

<Tabs bind:activeId={activeTab}>
  <Tab id="tab1" label="First">
    {#snippet content()}First content{/snippet}
  </Tab>
  <Tab id="tab2" label="Second">
    {#snippet content()}Second content{/snippet}
  </Tab>
</Tabs>

<button onclick={() => activeTab = "tab2"}>Go to Second</button>

CLOSABLE TABS
-------------
<script>
  let tabs = $state([
    { id: "tab1", label: "Document 1" },
    { id: "tab2", label: "Document 2" },
    { id: "tab3", label: "Document 3" }
  ])

  function closeTab(tabId: string) {
    tabs = tabs.filter(t => t.id !== tabId)
  }
</script>

<Tabs>
  {#each tabs as tab}
    <Tab
      id={tab.id}
      label={tab.label}
      showClose
      onTabClose={() => closeTab(tab.id)}
    >
      {#snippet content()}
        Content for {tab.label}
      {/snippet}
    </Tab>
  {/each}
</Tabs>

DYNAMIC TABS
------------
<script>
  let tabs = $state([
    { id: "1", label: "Tab 1" },
    { id: "2", label: "Tab 2" }
  ])

  function addTab() {
    const newId = String(tabs.length + 1)
    tabs = [...tabs, { id: newId, label: `Tab ${newId}` }]
  }
</script>

<button onclick={addTab}>Add Tab</button>

<Tabs>
  {#each tabs as tab}
    <Tab id={tab.id} label={tab.label}>
      {#snippet content()}
        Content for {tab.label}
      {/snippet}
    </Tab>
  {/each}
</Tabs>

OVERFLOW
--------
<Tabs responsive="menu">   <!-- or "scroll" (default) / "wrap" -->
  <Tab id="main" label="Main">
    {#snippet content()}Main content{/snippet}
  </Tab>
  ...
</Tabs>

"menu" collapses tabs that don't fit into a trailing overflow button + menu.


CHILDREN INSTEAD OF content
---------------------------

</Tab>


STYLING
-------
Plain DOM (no shadow parts). Main classes:
- .fluent-tabs / .fluent-tabs-strip / .fluent-tabs-tablist - container, strip, tablist
- .fluent-tab / .fluent-tab-label / .fluent-tab-icon / .fluent-tab-close - tab button parts
- .fluent-tabs-active-indicator - animated active indicator
- .fluent-tabs-panels / .fluent-tab-panel - panel container and panels

Target them with :global(...) from a parent component's styles.

COMMON ISSUES
-------------

Issue: Tab content not showing
Solution: Put content between the <Tab> tags or use {#snippet content()}

Issue: Active tab not tracked
Solution: Add unique id prop to each Tab

Issue: Tab change not firing
Solution: Use onActiveIdChange on Tabs (or bind:activeId)

Issue: Vertical tabs not working
Solution: Set orientation="vertical" on Tabs

Issue: Close button not visible
Solution: Add showClose prop to Tab
