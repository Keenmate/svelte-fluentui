NAVIGATION COMPONENTS
=====================

OVERVIEW
--------
Custom navigation components for sidebars and app bars.
Not FluentUI wrappers - built from scratch with FluentUI styling.


==============================================================================
NAVMENU
==============================================================================
Sidebar navigation menu container.

USAGE:
<script>
  import { NavMenu, NavGroup, NavLinkItem } from "svelte-fluentui"
  let collapsed = $state(false)
</script>

<NavMenu bind:collapsed collapsible width="250px">
  <NavGroup title="Main">
    <NavLinkItem href="/">Home</NavLinkItem>
    <NavLinkItem href="/dashboard">Dashboard</NavLinkItem>
  </NavGroup>
</NavMenu>

PROPS:
width?: string              # Menu width (default: "100%")
collapsed?: boolean         # Bindable - collapsed state
collapsible?: boolean       # Show collapse toggle
class?: string


==============================================================================
NAVGROUP
==============================================================================
Groups navigation items with optional title.

USAGE:
<NavGroup title="Settings">
  <NavLinkItem href="/settings/general">General</NavLinkItem>
  <NavLinkItem href="/settings/account">Account</NavLinkItem>
</NavGroup>

PROPS:
title?: string              # Group title
expanded?: boolean          # Expanded state (default: true)
class?: string


==============================================================================
NAVLINKITEM
==============================================================================
Navigation link with icon support.

Structure: outer <div role="menuitem"> (NavItem) wrapping the link (NavLink:
an <a> when href is set, otherwise a <div>).

USAGE:
<NavLinkItem href="/dashboard" title="Dashboard">
  {#snippet icon()}<Icon name="data_bar_vertical" />{/snippet}
  Dashboard
</NavLinkItem>

<!-- Anchor attributes for the inner <a> go through linkProps -->
<NavLinkItem href="/files/report.csv" linkProps={{ download: "report.csv" }}>
  Download report
</NavLinkItem>
<NavLinkItem href="https://github.com" linkProps={{ target: "_blank", rel: "noopener noreferrer" }}>
  GitHub
</NavLinkItem>

PROPS:
href?: string               # Link URL (renders an <a>)
rel?: string                # Applied only when href is set
target?: string
title?: string              # Tooltip (useful in collapsed mode)
disabled?: boolean
group?: boolean             # Style as a group header
linkProps?: HTMLAnchorAttributes  # Spread on the inner link element (download, hreflang,
                            # referrerpolicy, aria-current, data-*, onkeydown, ...);
                            # top-level href/rel/target/title win over the same keys
linkAction?: (node: HTMLElement) => void  # Svelte action on the inner link element
onclick?: (ev: MouseEvent) => void        # Native click, forwarded untouched
...rest                     # class, style, data-*, aria-*, ... -> OUTER div role="menuitem"

SNIPPETS:
children                    # Link text
icon                        # Icon before the text
afterText                   # Content after the text (e.g. a Badge)


==============================================================================
NAVITEM
==============================================================================
Generic navigation item (non-link).

USAGE:
<NavItem onclick={openSettings}>
  Settings
</NavItem>

PROPS:
disabled?: boolean
group?: boolean
onclick?: (ev: MouseEvent) => void
class?: string
...rest                     # -> root <div role="menuitem">
children: Snippet


==============================================================================
APPBAR / APPBARITEM
==============================================================================
Persistent bar of icon-and-label items for top-level navigation (inspired by
FluentUI Blazor AppBar). Vertical by default (a rail), or horizontal.
Not a header with start/end areas - it only lays out AppBarItem children.

USAGE:
<script>
  import { AppBar, AppBarItem, ResourcesIcon } from "svelte-fluentui"
  import { AppBarOrientation } from "svelte-fluentui/constants"
  let unread = $state(3)
</script>

{#snippet homeIcon()}
  <!-- part="icon-rest" / part="icon-active" swap on hover / active -->
  <ResourcesIcon aria-hidden="true" part="icon-rest" />
  <ResourcesIcon aria-hidden="true" part="icon-active" active />
{/snippet}

<AppBar>                                   <!-- or orientation={AppBarOrientation.Horizontal} -->
  <AppBarItem href="/" icon={homeIcon} active={path === "/"}>Home</AppBarItem>
  <AppBarItem href="/inbox" icon={homeIcon} count={unread}
              countLabel={(count) => `${count} unread`}>Inbox</AppBarItem>
  <AppBarItem href="https://example.com" target="_blank" rel="noopener noreferrer"
              icon={homeIcon}>External</AppBarItem>
  <AppBarItem onclick={openPanel} icon={homeIcon}>Panel</AppBarItem>
</AppBar>

APPBAR PROPS:
orientation?: "vertical" | "horizontal"   # AppBarOrientation enum (default vertical)
class?: string
...rest                     # Native attributes/events -> root <nav> (aria-label, id, ...)
children: Snippet           # AppBarItem components

APPBARITEM PROPS:
href?: string               # Link URL
count?: number              # Badge on the icon; hidden when 0 / undefined
maxCount?: number           # Default 99; above it the badge reads "99+"
countLabel?: (count: number) => string   # Accessible-name wording (localisation);
                            # gets the full uncapped count; default: bare number
active?: boolean            # Highlights the current item (app-controlled)
onclick?: (ev: MouseEvent) => void       # Native click, forwarded untouched
class?: string              # On the outer .fluent-appbar-item wrapper
...rest                     # HTMLAnchorAttributes -> inner <a> (target, rel, download,
                            # title, aria-label, aria-current, data-*, onkeydown, ...)

APPBARITEM SNIPPETS:
icon                        # Icon above the label
children                    # Label

COUNT ACCESSIBILITY:
The badge is aria-hidden; the full count (worded by countLabel) is appended to
the link's accessible name as visually hidden text: "Inbox, 3 unread".
A consumer aria-label gets it appended too: aria-label="Mailbox" ->
"Mailbox, 3 unread". aria-labelledby gets the hidden count text's id appended.

COUNT BADGE CSS VARIABLES (set on AppBar, an item class, or any ancestor):
--fluent-appbar-count-background     # default var(--accent-fill-rest)
--fluent-appbar-count-color          # default var(--foreground-on-accent-rest)
--fluent-appbar-count-ring-color     # 1px ring, default var(--neutral-layer-1)
--fluent-appbar-count-size           # height / min width / line height, 16px
--fluent-appbar-count-font-size      # 10px
--fluent-appbar-count-font-weight    # 600
--fluent-appbar-count-padding-inline # 4px
--fluent-appbar-count-radius         # 9999px (pill)
--fluent-appbar-count-offset-block   # -6px (from the icon's top edge)
--fluent-appbar-count-overlap        # 8px (how far the badge reaches over the icon's end edge; grows outward, RTL-aware)

.danger-count {
  --fluent-appbar-count-background: var(--fluent-color-danger);
  --fluent-appbar-count-color: var(--fluent-color-danger-contrast);
}


==============================================================================
BREADCRUMB
==============================================================================
Breadcrumb navigation (wraps fluent-breadcrumb).

USAGE:
<script>
  import { Breadcrumb, BreadcrumbItem } from "svelte-fluentui"
</script>

<Breadcrumb>
  <BreadcrumbItem href="/">Home</BreadcrumbItem>
  <BreadcrumbItem href="/products">Products</BreadcrumbItem>
  <BreadcrumbItem>Electronics</BreadcrumbItem>
</Breadcrumb>

BREADCRUMBITEM PROPS:
href?: string               # Link URL (last item typically has no href)
class?: string
...rest                     # Native + anchor attributes (target, rel, download, ...); anchor ones apply to the inner <a>
children: SlotType          # Item text

EXAMPLES
==============================================================================

SIDEBAR WITH GROUPS:
<NavMenu width="240px">
  <NavGroup title="Main">
    <NavLinkItem href="/">Home</NavLinkItem>
    <NavLinkItem href="/inbox">
      Inbox
      <Badge>12</Badge>
    </NavLinkItem>
  </NavGroup>

  <NavGroup title="Admin">
    <NavLinkItem href="/users">Users</NavLinkItem>
    <NavLinkItem href="/settings">Settings</NavLinkItem>
  </NavGroup>
</NavMenu>


COLLAPSIBLE SIDEBAR:
<script>
  let sidebarCollapsed = $state(false)
</script>

<NavMenu
  bind:collapsed={sidebarCollapsed}
  collapsible
  width="250px"
>
  <NavLinkItem href="/">Home</NavLinkItem>
  <NavLinkItem href="/dashboard">Dashboard</NavLinkItem>
</NavMenu>

When collapsed, only icons are visible (40px width).


ACTIVE LINK:
<script>
  import { page } from "$app/stores"
</script>

<NavMenu>
  <!-- NavLinkItem has no active prop; mark the current page on the inner <a> -->
  <NavLinkItem
    href="/dashboard"
    linkProps={{ "aria-current": $page.url.pathname === "/dashboard" ? "page" : undefined }}
  >
    Dashboard
  </NavLinkItem>
</NavMenu>


APP RAIL + SIDEBAR LAYOUT:
<Layout orientation="horizontal" style="min-height: 100vh">
  <AppBar aria-label="Main">
    <AppBarItem href="/" icon={homeIcon} active={path === "/"}>Home</AppBarItem>
    <AppBarItem href="/inbox" icon={mailIcon} count={unread}>Inbox</AppBarItem>
  </AppBar>

  <NavMenu bind:collapsed collapsible width="240px">
    <NavGroup title="Menu">
      <NavLinkItem href="/">Home</NavLinkItem>
      <NavLinkItem href="/about">About</NavLinkItem>
    </NavGroup>
  </NavMenu>

  <main><!-- Page content --></main>
</Layout>


BREADCRUMB NAVIGATION:
<script>
  const crumbs = [
    { href: "/", label: "Home" },
    { href: "/products", label: "Products" },
    { href: "/products/electronics", label: "Electronics" },
    { label: "Laptops" }  // Current page, no href
  ]
</script>

<Breadcrumb>
  {#each crumbs as crumb, i}
    <BreadcrumbItem href={crumb.href}>
      {crumb.label}
    </BreadcrumbItem>
  {/each}
</Breadcrumb>

==============================================================================
COMMON ISSUES
==============================================================================

Issue: Sidebar not collapsing
Solution: Bind to collapsed prop and add collapsible

Issue: Active state not showing
Solution: Set active prop based on current route

Issue: Icons not showing in collapsed mode
Solution: Icons are preserved, text hides automatically

Issue: Sidebar overflow
Solution: NavMenu has overflow: auto by default
